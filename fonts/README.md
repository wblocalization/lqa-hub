# Шрифты

`TwemojiCountryFlags.woff2` — флаги стран для Windows, где нет эмодзи флагов (вместо 🇰🇿 там видно «KZ»). В шрифте только флаги, остальной текст он не трогает.

- Рисунки флагов: [Twemoji](https://github.com/twitter/twemoji), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Сборка шрифта: [country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill) 0.1.10, лицензия MIT.
