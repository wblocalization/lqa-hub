# LQA Hub — выгрузка из Weblate в .po

Выгружает строки из Weblate в файлы .po. Можно выбрать один язык или несколько, один компонент или любые компоненты проекта. Готовые файлы сразу загружаются в LQA Hub на проверку.

## Установка (2 минуты, один раз)

1. В LQA Hub открой раздел **Расширение** → карточка «Выгрузка из Weblate» → **Скачать**. Распакуй архив, появится папка `lqa-hub-weblate`. Положи её туда, где она будет жить: если папку удалить, расширение пропадёт.
2. В Chrome открой `chrome://extensions` и справа вверху включи **Режим разработчика**.
3. **Загрузить распакованное расширение** → выбери папку `lqa-hub-weblate`.
4. Закрепи значок: пазл справа от адресной строки → булавка у «LQA Hub — выгрузка из Weblate».

## Как пользоваться

1. Войди в Weblate и открой нужный проект, компонент или перевод.
2. Нажми на значок расширения. Оно само определит проект, компонент и язык страницы.
3. Отметь **языки** и **компоненты**. По умолчанию отмечены язык и компонент открытой страницы, а если открыт проект — все компоненты.
4. Выбери, какие строки нужны:
   - **только переведённые** — по умолчанию;
   - **переведённые и «требуют правки»** — эти строки помечаются `#, fuzzy`;
   - **все строки**, включая пустые.
5. Выбери, как разложить по файлам: **один .po на язык** или **отдельный .po на каждый компонент**.
6. **Выгрузить .po** → файлы появятся в «Загрузках». Ход выгрузки виден и в окошке, и в правом нижнем углу страницы Weblate.

## Что внутри .po

- `msgctxt` — ключ строки (контекст из Weblate), `msgid` — исходник, `msgstr` — перевод.
- Множественное число записывается как `msgid_plural` и `msgstr[0]`, `msgstr[1]`…, а `Plural-Forms` берутся из Weblate.
- Комментарии к строке и её расположение попадают в `#.` и `#:`.
- Если в одном файле встречаются одинаковые строки из разных компонентов, к `msgctxt` добавляется имя компонента, чтобы строки не слились.

## Если не пускает

Расширение ходит в API Weblate под твоим входом, отдельный ключ обычно не нужен. Если всё равно пишет «Weblate не пускает в API», возьми API-ключ в Weblate: профиль → **API-доступ**. Вставь его в окошке расширения в поле «API-ключ Weblate». Ключ хранится только в этом браузере.

## Что расширение может и чего не может

- Работает только на вкладке, где ты нажала на значок, и только читает: в Weblate ничего не меняет.
- Никуда, кроме твоих «Загрузок», строки не отправляет.
- Глоссарии Weblate не выгружает, только обычные компоненты.
