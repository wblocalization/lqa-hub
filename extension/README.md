# LQA Hub — расширение для обхода страниц

Снимает скриншоты страниц Wildberries прямо в твоём браузере и складывает их в сессию визуальной проверки LQA Hub. Для сайта это обычный пользователь, поэтому защита от ботов его не блокирует. Если ты вошла в аккаунт WB, снимаются и страницы личного кабинета.

## Установка (2 минуты, один раз)

1. Скачай репозиторий: [Code → Download ZIP](https://github.com/wblocalization/lqa-hub/archive/refs/heads/main.zip) и распакуй.
2. В Chrome открой `chrome://extensions`.
3. Справа вверху включи **Режим разработчика**.
4. **Загрузить распакованное расширение** → выбери папку `extension` из распакованного архива.
5. Обнови страницу LQA Hub.

Обновить расширение после новой версии: скачай архив заново, замени папку и нажми ↻ на карточке расширения в `chrome://extensions`.

## Как пользоваться

1. В LQA Hub открой сессию визуальной проверки → **Обойти страницы**.
2. Впиши страницы (по одной в строке: `Название | ссылка`), выбери компьютер и/или телефон → **Начать обход**.
3. Откроется отдельное окно: робот по очереди открывает страницы, прокручивает их и снимает целиком. Пока он работает, это окно не закрывай. Вверху Chrome покажет полоску «LQA Hub начало отлаживать этот браузер» — это нормально: так расширение изображает телефон и снимает страницу целиком.
4. Скриншоты появляются в сессии по мере готовности. Если включено «Сразу распознать текст», после обхода запустится поиск обрезанного, непереведённого текста и видимых переменных.

## Что расширение может и чего не может

- Работает только на сайте LQA Hub (`wblocalization.github.io`) и снимает только сайты Wildberries (`wildberries.*`, `wb.ru`, `rwb.ru`). Другие сайты оно не откроет.
- Никуда, кроме открытой вкладки LQA Hub, скриншоты не отправляет.
- Мобильные приложения iOS/Android не снимает — только сайт, в том числе в размере телефона.
