# ИИ-backend для LQA Hub (Google Apps Script)

Этот скрипт соединяет платформу с ИИ-моделью. Он хранит ключ API у себя: ключ не попадает ни в браузер, ни в файл платформы. Один и тот же адрес проверяет:

- **строки перевода**: раздел «Проблемы», отметить строки → «ИИ-проверка выбранных»;
- **скриншоты**: раздел «Визуальная проверка», сессия → «ИИ-проверка».

Поддерживаются два провайдера: **Claude** (Anthropic) и **OpenAI**. Нужен ключ API одного из них.

## Установка (10 минут)

1. Открой [script.google.com](https://script.google.com) → **Новый проект**. Назови его, например, «LQA Hub AI».
2. Удали всё в файле `Code.gs` и вставь содержимое [`ai-review-appsscript.gs`](./ai-review-appsscript.gs). Нажми 💾 **Сохранить**.
3. Слева ⚙️ **Настройки проекта** → внизу **Свойства скрипта** → **Добавить свойство**. Добавь:

   | Свойство | Значение |
   |---|---|
   | `PROVIDER` | `anthropic` (Claude) или `openai` |
   | `ANTHROPIC_API_KEY` | ключ с [platform.claude.com](https://platform.claude.com), если выбрала `anthropic` |
   | `OPENAI_API_KEY` | ключ с [platform.openai.com](https://platform.openai.com), если выбрала `openai` |
   | `ACCESS_TOKEN` | придумай длинную случайную строку, например `lqa-7f3k9q2m8x`. Без неё backend будет отвечать любому, кто узнает адрес, и тратить твой лимит |
   | `MODEL` | *необязательно*: своя модель. По умолчанию `claude-opus-5` для Claude и `gpt-4o-mini` для OpenAI |

4. Проверь, что всё работает: сверху выбери функцию **`testConnection`** → **Выполнить**. При первом запуске Google попросит разрешения, разреши. В **Журнале выполнения** появится ответ модели по тестовой строке.
5. Справа сверху **Начать развертывание** → **Новое развертывание** → тип ⚙️ **Веб-приложение**:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все**. Иначе браузер не достучится. Защищает `ACCESS_TOKEN`.
   
   Нажми **Начать развертывание** и скопируй **URL веб-приложения**: он заканчивается на `/exec`.
6. В платформе: **Настройки → Проверка ИИ**:
   - Backend: **Включён**;
   - Адрес backend: вставь URL из шага 5;
   - Ключ доступа: тот же текст, что в `ACCESS_TOKEN`;
   - нажми **Сохранить**, потом **Проверить подключение**. Должно появиться «✓ Работает: Claude, модель claude-opus-5» (или OpenAI).

## Если что-то не так

| Что видишь | Что сделать |
|---|---|
| «Не удалось достучаться» | Проверь, что URL заканчивается на `/exec`, а в развертывании доступ «Все». |
| «Неверный ключ доступа» | Текст в поле «Ключ доступа» должен совпадать с `ACCESS_TOKEN` до символа. |
| «…ответил 401: неверный ключ API» | Проверь `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` и что на аккаунте провайдера есть баланс. |
| «…ответил 429» | Слишком много запросов подряд или закончился лимит. Подожди минуту. |
| «Ответ модели оборвался» или долгие проверки строк | Уменьши «Строк за один вызов» в Настройках, например до 10. |
| Поменяла код скрипта, а работает по-старому | После правок нужно **Развертывание → Управление развертываниями → ✏️ → Версия: новая → Развернуть**. URL при этом не меняется. |

## Сколько это стоит

Платишь провайдеру за каждый запрос. Проверка одного скриншота 1280×720 — это примерно 1–2 тысячи токенов на входе плюс ответ. Пачка из 15 строк — в том же порядке. Актуальные цены: [Claude](https://platform.claude.com/docs/en/about-claude/pricing), [OpenAI](https://openai.com/api/pricing). Чтобы тратить меньше, запускай ИИ по строкам, которые уже отметила техническая проверка, и по скриншотам, где что-то подозрительно.

## Как это устроено (для разработчика)

Платформа шлёт `POST` на URL веб-приложения, тело — JSON (`Content-Type: text/plain`, чтобы Apps Script не требовал CORS preflight). Поле `token` сверяется с `ACCESS_TOKEN`.

- `{"mode":"ping"}` → `{"ok":true,"provider":"anthropic","model":"claude-opus-5"}`
- `{"mode":"visual","image":"data:image/webp;base64,…","language":"kk","languageName":"Казахский","page":"Главная","pageUrl":"…","glossary":[{"term","approved"}]}`
  → `{"findings":[{"type","severity","text","found","expected","box":{"x","y","w","h"}}]}`. Рамка задаётся в долях от размера картинки (0..1).
- `{"items":[{"id","source","target","language","component","context","glossary"}]}`
  → `{"results":[{"id","has_issue","type","severity","explanation","suggestion","confidence"}]}`
- При ошибке: `{"error":"текст ошибки"}`.

Ответ модели ограничен JSON-схемой (structured outputs у обоих провайдеров), поэтому типы и важность всегда из списков платформы. Для Claude Opus 5 включены серверные fallbacks (`fallbacks: "default"`): если фильтр безопасности отклонит запрос, API сам повторит его на подходящей модели.
