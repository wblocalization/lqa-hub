# Автотесты

Тесты открывают `index.html` в Chromium и проходят по платформе как пользователь: загружают .po, создают папки, ищут через палитру команд, распознают текст на скриншоте. Запускаются сами на каждый pull request и push в `main` (GitHub → вкладка **Actions** → «Автотесты»).

## Запустить у себя

```bash
npm install
npx playwright install chromium
npm test
```

| Файл | Что проверяет |
|---|---|
| `checks.spec.js` | Техническая проверка: переменные, числа, пробелы, смешанные алфавиты, правила языков, «игнорировать» |
| `folders.spec.js` | Подпапки, удаление файла с «Отменить», удаление папки с подпапками, история перевода |
| `navigation.spec.js` | Все разделы открываются без ошибок, палитра команд, сохранённые фильтры, отчёт за период |
| `perf.spec.js` | 20 000 строк загружаются и обновляются новой версией быстро |
| `glossary-export.spec.js` | Глоссарий со словоформами, скачивание исправленного .po |
| `google.spec.js` | Вход через Google (Google подменён заглушкой) |
| `extension.spec.js` | Расширение для обхода страниц: грузится в Chromium, снимает имитацию сайта на компьютере и телефоне |
| `online.spec.js` | Орфография и распознавание текста. Нужен интернет (словари и движок качаются с jsDelivr), поэтому идут в GitHub Actions или с `RUN_ONLINE_TESTS=1` |

Если тест упал в GitHub, в запуске есть архив **playwright-report**: там снимок страницы и пошаговая запись (trace).
